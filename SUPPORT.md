# NotesAI support

For installation problems, bugs, or feature requests, [open an issue in the NotesAI repository](https://github.com/chetanbavdhankar/notesai-info/issues).

Include your Windows version, NotesAI version, the steps that reproduce the problem, and any error message. GitHub issues are public. Do not include API keys, Google credentials, private notes, backup files, or other personal information. Review and redact screenshots and logs before posting.

For privacy questions, use the private contact listed in the [NotesAI Privacy Policy](PRIVACY.md), rather than posting personal information in an issue.
