# NotesAI

NotesAI is a Windows desktop app for capturing notes and links, organizing a personal knowledge library, and asking questions with source references using your chosen AI provider.

Published by **Monad Cosmos Labs**.

- [Privacy policy](PRIVACY.md)
- [Support and contact](SUPPORT.md)
- [Report a bug or request a feature](https://github.com/chetanbavdhankar/notesai-info/issues)

## Requirements

Windows 11 on an Intel or AMD 64-bit PC, with Microsoft Edge WebView2. Internet is required for the initial embedding-model download and optional online features. Text generation requires a compatible local model server or your own remote AI provider account; provider charges may apply. Google Drive backup requires your own Google Desktop OAuth client setup.

Notes and indexes are stored locally. Remote AI sends relevant content to the provider you configure. Google Drive backup is optional. See the privacy policy for details.

This repository contains public product information and support resources only. The application source code is maintained separately in a private repository. No application source code or source-code history is published here.

For private support or privacy questions, email **monad.cosmos.labs@gmail.com**. Never post API keys, credentials, private notes or backups in public issues.
